An entry for the [make.fun](https://make.fun/c/u-po-pu-one-star-five-stars-for-the-food-f9166ee7) competition **"One Star, Five Stars for the Food"**.

## What it does

`main.py` (pure Python standard library, no network, no secrets) writes a
single sentence — at most 200 characters — to `/output/entry.txt`: a one-star
review of planet Earth written by an alien tourist that still slips in a real
compliment about the food.

> One star: the humans charge rent for air, queue for hours to eat standing up, and yet the street noodles were so good I considered defecting to Earth.

## Run it

```sh
python3 main.py   # writes /output/entry.txt (or $OUTPUT_DIR/entry.txt)
```
